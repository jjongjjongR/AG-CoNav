# sim_env — 시뮬레이션 환경 / 스토리

**담당:** 채현우 (메인) · 이종헌 (도우미)

Gazebo Harmonic + ROS2 Jazzy 기반의 전시 시가지 환경과 3종 로봇 스폰을 담당한다.

## 스토리

전쟁 중 시가지. 잔해(rubble)로 인해 **4족 전용 / 4륜 전용 / 공용** 구간이 자연스럽게 형성된다. 목표점은 보급품 전달 지점이며 난이도가 태깅된다. 아군 위치는 마커로 인지(고도화: 사람 인지).

## 범위

- Gazebo Harmonic + ROS2 Jazzy 환경 세팅, 빌드/런치 파이프라인
- 시가지 맵 + 전쟁 잔해 배치 → 지형 난이도 구간 형성
- 목표점 배치 및 난이도 태깅 (4족전용/4륜전용/공용 비율)
- 아군 위치 마커 인지 (고도화: 사람 인지)
- 로봇 3종 스폰, 멀티로봇 네임스페이스, `ros_gz_bridge`, RViz2

## 결정 필요

- 시가지 맵 직접 제작 vs 기존 에셋 활용
- 목표점 개수·난이도 태깅 기준
- SLAM 사용 vs 정적 맵

## 구조(예정)

```
sim_env/
├── worlds/        # .sdf 시가지 월드, 잔해 배치
├── models/        # 로봇·잔해·마커 모델
├── launch/        # 환경·스폰 런치
└── config/        # 네임스페이스·브릿지 설정
```
