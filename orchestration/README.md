# orchestration — 탐지융합·로봇선택·임무배분

**담당:** 이종헌

세 로봇의 탐지를 융합해 통합 목표 리스트를 만들고, 목표별로 더 나은 로봇을 선택·배분한다. 실패 시 재계획하며, 전체 임무를 상태머신(FSM)으로 관리한다.

## 범위

- **탐지 융합:** 드론 전역 + 지상 국소 → 통합 목표 리스트
- **로봇 선택:** 목표 확정 시 4족 vs 4륜 도달성·비용 비교 → 더 나은 로봇 파견
  - 비용 = 이동시간 + 위험(경사/잔해/전복) + traversability 통과 가능성
  - 규칙 기반 선택(가깝고 명백한 경우) vs 최적 비교
- **임무 배분:** 목표–로봇 도달가능성 매트릭스 → 전체 완료시간·안전 최소화
- **재계획:** 실패 이벤트 → 재배분 트리거. LLM 재배분 vs 규칙 재배분 비교
- **FSM:** 전체 임무 상태머신

## 인터페이스(예정)

- 입력: 각 로봇 탐지 토픽, 통과 실패 이벤트, trav 지도 2종
- 출력: 로봇별 목표 배정, 재배분 명령

## 연구 질문

지형 정보·최적 배분·LLM 재배분이 임무 완료시간과 안전에 주는 영향 (→ [experiments](../experiments) Ablation).

## 구조(예정)

```
orchestration/
├── fusion/         # 탐지 융합
├── assign/         # 도달성 매트릭스·최적 배분
├── select/         # 로봇 선택(규칙/최적)
├── replan/         # 재계획(규칙/LLM)
└── fsm/            # 임무 상태머신
```
