# experiments — 실험 / 평가 / 문서화

**담당:** 전원 분담

## 평가 지표

- 임무 완료시간
- 주행 실패율
- 위험구간 선택률
- 로봇 선택 정확도
- 배분 효율

## Ablation

- 지형정보 **사용 / 미사용**
- 배분·선택: **최적 / 규칙**
- 재배분: **LLM / 규칙**

## 산출물

결과 표·그래프, 데모 영상, 논문/발표 자료.

## 구조(예정)

```
experiments/
├── configs/        # 시나리오·Ablation 설정
├── scripts/        # 실행·집계 스크립트
├── results/        # rosbag·로그·지표 산출
├── figures/        # 표·그래프
└── media/          # 데모 영상
```
